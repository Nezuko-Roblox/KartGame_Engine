# 鬼灭之刃题材小游戏系统文档（精简版）

本系统文档包含鬼灭之刃题材小游戏的核心玩法与外围系统设计，适用于Roblox等轻量级平台开发参考。涵盖角色养成、抽卡、任务、活动、关卡等主要功能模块。

---

## 1. 英雄卡池/抽卡系统
- 玩家可通过抽卡获得不同稀有度的鬼灭角色。
- 抽卡分为免费与付费（金币/钻石）方式，含保底机制。
- 角色按稀有度分级（如SSR、SR、R），抽卡概率公开透明。

## 2. 角色养成系统

### 2.1 角色升级
- 角色升级需消耗金币，每次升级提升攻击、生命、防御等基础属性。
- 升级上限受角色星级限制，如1星最大20级，2星最大40级，3星最大60级等。

### 2.2 角色升星
- 通过收集角色碎片或特定道具进行升星。
- 升星提升基础属性及最大等级上限，并可带来外观变化（如特效、装饰）。
- 升星不影响技能解锁或技能等级上限。

### 2.3 呼吸术/血鬼术系统
- 每位角色拥有专属呼吸术或血鬼术。
- 呼吸术/血鬼术升级需消耗金币或材料。
- 随呼吸术/血鬼术等级提升，自动解锁新技能（如炭治郎的水之呼吸·壹之型、肆之型、火之神神乐等）。
- 已解锁技能可继续升级，提升伤害或效果，技能等级仅受呼吸术/血鬼术等级限制。

---

## 3. 活动与签到系统
- 每日签到获得奖励，连续签到有额外奖励。
- 限时活动（节日、联动等）提供特殊关卡、限定角色或皮肤。

## 4. 排行榜与成就系统
- 按关卡进度、最高分、最快通关等排名。
- 成就系统：如通关特定关卡、收集全角色、完成特殊挑战等，获得称号或奖励。

## 5. 商城系统
- 玩家可使用金币、钻石等货币购买道具、角色碎片、抽卡次数等。
- 付费礼包、成长基金、限时特供商品，提升付费转化。
- 商店每日刷新，部分商品限时供应。

## 6. 任务与日常系统
- 主线任务：引导玩家体验核心玩法。
- 日常任务：通关、抽卡等获得奖励。
- 每周挑战任务，奖励更丰富。

## 7. 关卡与副本扩展
- 普通、精英、Boss关卡，难度递进。
- 无限/爬塔模式：无尽挑战，争夺高分与奖励。
- 限时副本：挑战特殊Boss或怪物。

## 8. 资料/图鉴系统
- 角色图鉴：展示已获得和未获得角色，技能及背景。
- 怪物图鉴：展示敌人属性、技能。
- 装备图鉴：收集和查看各种装备（如有装备系统）。

---

## 总结
本系统围绕鬼灭之刃IP，采用抽卡+养成核心玩法，辅以活动、任务、排行、图鉴等外围系统，提升玩家活跃度和体验乐趣。养成系统简洁明了，角色成长与技能成长分离，适合快速上手和持续养成。可根据实际需求对各模块进行细化和扩展。
