## 一、核心物理参数

### 1.1 基础物理属性

#### `mass` - 赛车质量
- **位置**: `PhysicSpec.lua` 第20行
- **默认值**: 100.0 kg
- **作用**: 赛车的质量，影响惯性、加速度和碰撞响应
- **使用场景**: 
  - `GoPlayKart.lua:212` - 计算重力作用力
  - `GoPlayKart.lua:238,240` - 计算刹车时的惯性力
  - `GoPlayKart.lua:534` - 计算悬挂弹簧刚度
- **影响**: 质量越大，加速越慢但稳定性越好

#### `airFriction` - 空气摩擦力
- **位置**: `PhysicSpec.lua` 第21行
- **默认值**: 3.0
- **作用**: 赛车在空中或低速时的线性阻力系数
- **使用场景**: 
  - `GoPlayKart.lua:171-172` - 计算线性和角速度阻力
- **公式**: `阻力 = -velocity * airFriction`
- **影响**: 值越大，滑行距离越短

#### `dragFactor` - 速度阻力系数
- **位置**: `PhysicSpec.lua` 第22行
- **默认值**: 0.74
- **作用**: 速度平方阻力系数，限制最高速度
- **使用场景**: 
  - `GoPlayKart.lua:180` - 计算速度平方阻力
- **公式**: `阻力 = -velocity * |velocity| * dragFactor`
- **影响**: 值越小，最高速度越高

#### `driftDragReduceFactor` - 漂移阻力减少系数
- **位置**: `PhysicSpec.lua` 第42行
- **默认值**: 0.4
- **作用**: 漂移时阻力变为原来的百分比
- **使用场景**: 
  - `GoPlayKart.lua:178` - 漂移时动态调整阻力
- **影响**: 值越小，漂移时速度保持越好

### 1.2 加速与制动

#### `forwardAccel` - 前进加速力
- **位置**: `PhysicSpec.lua` 第23行
- **默认值**: 4000.0 N
- **作用**: 赛车向前加速的推力
- **使用场景**: 
  - `GoPlayKart.lua:229,232` - 计算前进推力
- **影响**: 值越大，加速越快

#### `backwardAccel` - 后退加速力
- **位置**: `PhysicSpec.lua` 第24行
- **默认值**: 1500.0 N
- **作用**: 赛车倒车时的推力
- **使用场景**: 倒车时替代forwardAccel使用
- **影响**: 通常设置为前进力的30-40%

#### `gripBrake` - 抓地刹车力
- **位置**: `PhysicSpec.lua` 第25行
- **默认值**: 1800.0 N
- **作用**: 轮胎有抓地力时的刹车力
- **使用场景**: 
  - `GoPlayKart.lua:258` - 正常刹车时使用
- **影响**: 值越大，刹车距离越短

#### `slipBrake` - 打滑刹车力
- **位置**: `PhysicSpec.lua` 第26行
- **默认值**: 1200.0 N
- **作用**: 轮胎打滑或漂移时的刹车力
- **使用场景**: 
  - `GoPlayKart.lua:261` - 漂移刹车时使用
- **影响**: 通常设置为gripBrake的60-70%

### 1.3 赛车尺寸参数

#### `width` - 赛车宽度
- **位置**: `GoPlayKart.lua` 第527行、941行
- **计算方式**: `Min(0.98, 模型宽度 * 0.5)`
- **作用**: 赛车的半宽度，用于悬挂点计算
- **使用场景**: 
  - `GoPlayKart.lua:206` - 计算悬挂力矩
  - `GoPlayKart.lua:610` - 计算轮胎位置

#### `length` - 赛车长度
- **位置**: `GoPlayKart.lua` 第528行、942行
- **计算方式**: `模型长度 * 0.5`
- **作用**: 赛车的半长度，用于悬挂点计算
- **使用场景**: 
  - `GoPlayKart.lua:206` - 计算悬挂力矩
  - `GoPlayKart.lua:611` - 计算轮胎位置

## 二、转向控制参数

### 2.1 转向限制

#### `maxSteerDeg` - 最大转向角度
- **位置**: `PhysicSpec.lua` 第27行
- **默认值**: 4.0 度
- **作用**: 方向盘能转动的最大角度
- **转换**: `maxSteerRad = π * maxSteerDeg / 180`
- **使用场景**: 转向力计算的角度限制
- **影响**: 值越大，转弯半径越小

#### `steerConstraint` - 速度转向约束
- **位置**: `PhysicSpec.lua` 第28行
- **默认值**: 30.0
- **作用**: 速度对转向的抑制系数
- **公式**: `实际转向 = 输入转向 / (1 + 速度/steerConstraint)`
- **使用场景**: `GoPlayKart.lua` - 计算速度相关的转向衰减
- **影响**: 值越小，高速时转向越迟钝

### 2.2 抓地力参数

#### `frontGripFactor` - 前轮抓地力系数
- **位置**: `PhysicSpec.lua` 第29行
- **默认值**: 5.0
- **作用**: 前轮的侧向抓地力
- **使用场景**: 计算转向力和防止前轮打滑
- **影响**: 值越高，转向响应越好，但太高会过度灵敏

#### `rearGripFactor` - 后轮抓地力系数
- **位置**: `PhysicSpec.lua` 第30行
- **默认值**: 5.0
- **作用**: 后轮的侧向抓地力
- **使用场景**: 防止车尾甩动，维持稳定性
- **影响**: 值越低，越容易甩尾和漂移

### 2.3 转向倾斜效果

#### `steerLeanFactor` - 转向倾斜系数
- **位置**: `PhysicSpec.lua` 第37行
- **默认值**: 0.01
- **作用**: 正常转向时车身的倾斜程度
- **使用场景**: 视觉效果，增强转向感
- **影响**: 纯视觉参数，不影响物理

## 三、漂移系统参数

### 3.1 漂移触发

#### `driftTrigFactor` - 漂移触发系数
- **位置**: `PhysicSpec.lua` 第31行
- **默认值**: 0.2
- **作用**: 侧滑角度达到此值时触发漂移
- **使用场景**: 判断是否进入漂移状态
- **影响**: 值越小，越容易触发漂移

#### `driftTrigTime` - 漂移触发时间
- **位置**: `PhysicSpec.lua` 第32行
- **默认值**: 0.2 秒
- **作用**: 需要保持侧滑状态多久才能进入漂移
- **使用场景**: 防止意外触发漂移
- **影响**: 值越小，漂移响应越快

### 3.2 漂移行为

#### `driftSlipFactor` - 漂移滑动系数
- **位置**: `PhysicSpec.lua` 第33行
- **默认值**: 0.3
- **作用**: 漂移时后轮的滑动程度
- **使用场景**: 控制漂移角度和滑动感
- **影响**: 值越大，漂移角度越大

#### `driftEscapeForce` - 漂移推进力
- **位置**: `PhysicSpec.lua` 第34行
- **默认值**: 2500.0 N
- **作用**: 漂移时的前进推力
- **使用场景**: 
  - `GoPlayKart.lua:230,233` - 漂移时替代正常加速力
- **影响**: 值越大，漂移时速度损失越少

#### `driftLeanFactor` - 漂移倾斜系数
- **位置**: `PhysicSpec.lua` 第36行
- **默认值**: 0.07
- **作用**: 漂移时车身的倾斜角度
- **使用场景**: 增强漂移视觉效果
- **影响**: 纯视觉参数

### 3.3 漂移计量

#### `driftMaxGauge` - 漂移能量上限
- **位置**: `PhysicSpec.lua` 第38行
- **默认值**: 4000.0
- **作用**: 漂移能量槽的最大值
- **使用场景**: 积累漂移能量获得加速
- **影响**: 值越小，越快获得漂移加速

#### `cornerDrawFactor` - 弯道牵引系数
- **位置**: `PhysicSpec.lua` 第35行
- **默认值**: 0.2
- **作用**: 漂移过弯时的额外牵引力
- **使用场景**: 帮助维持漂移轨迹
- **影响**: 值越大，漂移越容易控制

### 3.4 漂移控制状态 (DriftControl.lua)

#### `slipMode` - 滑移模式
- **位置**: `DriftControl.lua` 第12行
- **类型**: boolean
- **作用**: 标记是否处于滑移状态

#### `slipTime` - 滑移时间
- **位置**: `DriftControl.lua` 第13行
- **默认值**: 0.0
- **作用**: 记录滑移持续时间

#### `forceSlip` - 强制滑移
- **位置**: `DriftControl.lua` 第14行
- **类型**: boolean
- **作用**: 强制进入滑移状态（如使用道具）

#### `trigger` - 漂移触发
- **位置**: `DriftControl.lua` 第15行
- **类型**: boolean
- **作用**: 标记漂移是否被触发

#### `triggerTime` - 触发时间
- **位置**: `DriftControl.lua` 第16行
- **默认值**: 0.0
- **作用**: 记录触发持续时间

### 3.5 漂移计量器 (DriftGauge.lua)

#### `gauge` - 当前能量值
- **位置**: `DriftGauge.lua` 第12行
- **范围**: 0 - driftMaxGauge
- **作用**: 当前积累的漂移能量

#### `progressOn` - 进度开关
- **位置**: `DriftGauge.lua` 第13行
- **类型**: boolean
- **作用**: 是否正在积累能量

#### `progress` - 当前进度
- **位置**: `DriftGauge.lua` 第14行
- **作用**: 当前帧的能量积累速度

## 五、悬挂系统参数

### 5.1 悬挂行程

#### `maxTravel` - 最大悬挂行程
- **位置**: `Suspension.lua` 第39行
- **默认值**: 0.3 米
- **作用**: 悬挂能压缩的最大距离
- **使用场景**: 越野和过坎
- **影响**: 值越大，越野能力越强

#### `travel` - 当前行程
- **位置**: `Suspension.lua` 第40行
- **默认值**: [0.3, 0.3, 0.3, 0.3]
- **作用**: 四个轮子的当前悬挂压缩量
- **索引**: [左前, 右前, 左后, 右后]

#### `deltaTravel` - 行程变化
- **位置**: `Suspension.lua` 第41行
- **默认值**: [0.0, 0.0, 0.0, 0.0]
- **作用**: 悬挂压缩速度，用于阻尼计算

### 5.2 悬挂刚度与阻尼

#### `springK` - 弹簧刚度
- **位置**: `GoPlayKart.lua` 第534行
- **计算**: `mass * |gravity| * 0.5`
- **作用**: 悬挂弹簧的刚度系数
- **使用场景**: 
  - `GoPlayKart.lua:192,194` - 计算悬挂支撑力
- **影响**: 值越大，悬挂越硬

#### `damperCopC` - 压缩阻尼
- **位置**: `GoPlayKart.lua` 第535行
- **默认值**: 0
- **作用**: 悬挂压缩时的阻尼系数
- **使用场景**: 
  - `GoPlayKart.lua:194` - 悬挂压缩时使用
- **影响**: 防止悬挂过快压缩

#### `damperRebC` - 回弹阻尼
- **位置**: `GoPlayKart.lua` 第536行
- **计算**: `springK * 0.2`
- **作用**: 悬挂回弹时的阻尼系数
- **使用场景**: 
  - `GoPlayKart.lua:192` - 悬挂回弹时使用
- **影响**: 防止悬挂震荡

### 5.3 轮胎配置

#### `wheelOff` - 轮胎偏移
- **位置**: `Suspension.lua` 第21-27行
- **默认值**: 
  - [1]: (-1.0, 1.0) 左前
  - [2]: (1.0, 1.0) 右前
  - [3]: (-1.0, -1.0) 左后
  - [4]: (1.0, -1.0) 右后
- **作用**: 四个轮胎相对车身中心的位置
- **使用场景**: 计算每个轮胎的受力点

#### `wheelContact` - 轮胎接触
- **位置**: `Suspension.lua` 第29-32行
- **类型**: boolean[4]
- **作用**: 标记每个轮胎是否接触地面
- **使用场景**: 判断是否施加地面力

#### `wheelContactN` - 接触法线
- **位置**: `Suspension.lua` 第34-37行
- **类型**: Vector3[4]
- **作用**: 每个轮胎接触点的地面法线
- **使用场景**: 计算地面支撑力方向

## 六、驾驶模式参数

### 6.1 DriveFactor配置结构

#### 基础参数 (DriveFactor.lua)

##### `frontGripFactor` - 前轮抓地修正
- **位置**: `DriveFactor.lua` 第12行
- **默认值**: 0.0
- **作用**: 动态调整前轮抓地力
- **使用方式**: 负值表示相对于基础值的减少量

##### `rearGripFactor` - 后轮抓地修正
- **位置**: `DriveFactor.lua` 第13行
- **默认值**: 0.0
- **作用**: 动态调整后轮抓地力
- **使用方式**: 负值表示相对于基础值的减少量

##### `driftSlipFactor` - 漂移滑动修正
- **位置**: `DriveFactor.lua` 第14行
- **默认值**: 1.0
- **作用**: 调整漂移时的滑动程度
- **使用方式**: 倍数系数

##### `betaCut` - 转向限制系数
- **位置**: `DriveFactor.lua` 第18行
- **默认值**: 1.0
- **作用**: 限制转向输入的比例
- **范围**: 0.0-1.0

##### `speedLimit` - 速度限制
- **位置**: `DriveFactor.lua` 第22行
- **默认值**: 120.0
- **作用**: 当前模式的最高速度限制
- **单位**: 游戏单位/秒

#### 转向速度调整

##### `onDriftSteerFactor` - 漂移中转向系数
- **位置**: `DriveFactor.lua` 第19行
- **默认值**: 0.7
- **作用**: 漂移时转向速度为正常的70%
- **影响**: 防止漂移时过度转向

##### `onRestTimeSteerFactor` - 恢复时转向系数
- **位置**: `DriveFactor.lua` 第20行
- **默认值**: 0.8
- **作用**: 漂移恢复阶段的转向速度
- **影响**: 平滑漂移退出过程

##### `onTriggerSteerFactor` - 触发时转向系数
- **位置**: `DriveFactor.lua` 第21行
- **默认值**: 1.0
- **作用**: 漂移触发阶段的转向速度
- **影响**: 保持正常转向响应

### 6.2 模式配置实例

#### 正常驾驶模式
- **位置**: `GoPlayKart.lua` 第104-107行
- **配置**:
  ```lua
  m_DriveFactor[2][1].speedLimit = 340      -- 最高速度
  m_DriveFactor[2][1].betaCut = 0.6         -- 转向限制60%
  m_DriveFactor[2][1].frontGripFactor = -1  -- 前轮抓地力-1
  m_DriveFactor[2][1].rearGripFactor = -1   -- 后轮抓地力-1
  m_DriveFactor[2][2].betaCut = 0.85        -- 备用转向限制85%
  ```

#### 漂移模式
- **位置**: `GoPlayKart.lua` 第109-113行
- **配置**:
  ```lua
  m_DriveFactor[3][1].speedLimit = 180      -- 漂移速度限制
  m_DriveFactor[3][1].betaCut = 0.6         -- 转向限制60%
  m_DriveFactor[3][1].driftSlipFactor = 0.5 -- 滑动系数50%
  m_DriveFactor[3][2].frontGripFactor = -2  -- 前轮抓地力-2
  m_DriveFactor[3][2].rearGripFactor = -2   -- 后轮抓地力-2
  ```

## 参数之间的关联性

### 1. 质量与力的关系
- `mass` 影响所有力的效果
- 增加质量需要同比增加 `forwardAccel`、`gripBrake` 等
- 悬挂刚度 `springK` 自动根据质量计算

### 2. 抓地力平衡
- `frontGripFactor` 和 `rearGripFactor` 的比例决定转向特性
- 前高后低：转向过度（容易甩尾）
- 前低后高：转向不足（推头）
- 建议保持 1:1 或轻微调整

### 3. 漂移系统联动
- `driftTrigFactor` 决定进入难度
- `driftSlipFactor` 控制漂移程度
- `driftEscapeForce` 保持漂移速度
- `driftDragReduceFactor` 减少速度损失
- 这四个参数需要协调调整

### 4. 速度与阻力
- `forwardAccel` 提供推力
- `airFriction` 提供线性阻力
- `dragFactor` 提供平方阻力（限制最高速度）
- 最高速度 ≈ sqrt(forwardAccel / (mass * dragFactor))

### 5. 转向与速度
- `steerConstraint` 让高速时转向变迟钝
- 实际转向角 = maxSteerDeg / (1 + speed/steerConstraint)
- 配合 `DriveFactor` 的速度限制使用
