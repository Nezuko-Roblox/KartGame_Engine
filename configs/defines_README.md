# Luban配置表定义文件

这个目录包含了从 `src/shared/configs` 转换而来的Luban配置表定义文件。

## 文件结构

### 基础定义

- `resource.xml` - 资源系统基础配置，提供通用的资源属性
- `main.xml` - 主配置模块，整合所有配置类型

### 游戏系统定义

- `item.xml` - 物品系统配置定义
- `egg.xml` - 蛋类系统配置定义
- `boombox.xml` - 音箱系统配置定义
- `potion.xml` - 药水系统配置定义
- `mutation.xml` - 变异系统配置定义
- `island.xml` - 岛屿系统配置定义
- `size.xml` - 尺寸系统配置定义
- `hammer.xml` - 锤子系统配置定义
- `bundle.xml` - 捆绑包系统配置定义
- `expand.xml` - 扩展系统配置定义
- `foreverpack.xml` - 永久包系统配置定义
- `globalevent.xml` - 全局事件系统配置定义
- `portal.xml` - 传送门系统配置定义
- `tutorial.xml` - 教程系统配置定义

## 设计原则

1. **移除函数依赖**: 原始配置中的 `GetModel` 等函数被转换为字符串路径
2. **类型安全**: 使用Luban的强类型系统确保配置的正确性
3. **继承结构**: 利用 `resource.xml` 中的基础类型减少重复定义
4. **模块化**: 每个游戏系统独立定义，便于维护和扩展

## 主要变更

- `Model` 类型改为 `string` 类型的路径
- 函数调用移除，保留纯配置数据
- 添加了 `id` 字段用于唯一标识
- 规范化了命名约定（驼峰式转换为下划线式）
- 增加了类型安全的枚举定义

## 使用方法

这些定义文件可以被Luban工具用来生成对应的配置表结构和代码。每个定义文件都包含了完整的类型信息和注释，确保生成的配置表易于理解和使用。
